# DAON Agent System v1.0.0 — 배포 패키지

이 폴더에는 두 가지 설치 형태가 들어 있습니다. **둘 중 하나만** 골라 설치하세요.

---

## 옵션 A. NSIS 인스톨러 (일반 사용자 권장)

파일: `DAON Agent System Setup 1.0.0.exe`

- 더블클릭 → 안내에 따라 설치.
- 시작 메뉴 / 바탕화면 바로가기 자동 생성.
- 설치 중 앱이 실행 중이면 자동으로 종료 후 진행됩니다.

> ⚠ 참고: 일부 PC(실시간 파일 감시 프로그램 — 예: ProtonDrive, Windows Defender — 이
> 동작하는 환경)에서는 1.1GB 서버 파일 압축 해제 중 진행률이 멈춰 보이는 경우가 있습니다.
> 그 경우 아래 **옵션 B(포터블 zip)** 를 사용하세요. 포터블은 단순 파일 복사(robocopy)
> 방식이라 멈춤 없이 수 초 안에 끝납니다.

---

## 옵션 B. 포터블 zip (설치 멈춤 환경 / 무설치 선호)

파일: `DAON-Agent-System-1.0.0-portable.zip`

1. zip을 원하는 위치에 압축 해제합니다.
2. 압축 해제한 폴더 안의 **`install.bat`** 를 더블클릭합니다.
   - (또는 PowerShell에서 `install.ps1` 실행)
3. 스크립트가 아래 작업을 자동으로 수행합니다:
   - 폴더 전체를 `%LOCALAPPDATA%\Programs\DAON Agent System` 으로 복사
   - 자동 업데이트 설정(`app-update.yml`) 제거 (NSIS 재다운로드 방지)
   - 바탕화면 + 시작 메뉴 바로가기 생성
4. 완료 메시지가 뜨면 바탕화면 바로가기로 실행합니다.

---

## 공통 참고

- 앱은 **64비트(x64)** 입니다. (NSIS 인스톨러의 부트로더만 x86이며 정상입니다.)
- 서버(`server.exe`)가 백그라운드로 함께 실행됩니다. 트레이 아이콘으로 상주합니다.
- 화면 꺼짐 / 화면 보호기는 서버를 멈추지 않습니다. 다만 **절전 모드(S3)** 에 진입하면
  서버도 중단됩니다. 서버를 계속 돌리려면 전원 설정에서 절전 모드를 "안 함"으로 두세요.

## 버전 확인

설치 후 새 빌드 여부 확인:
- 설치 폴더 `resources\server.exe` 의 수정 날짜가 이번 빌드 날짜와 일치하는지 확인.
- 또는 앱 로그에 `agent_log` / `execute_dynamic_harness` 문자열이 있는지 확인.
